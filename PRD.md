## 1. Обзор продукта

### 1.1. Главная идея
**«Вся моя жизнь, мои планы и мечты — в одном месте».**

Персональное приложение, которое объединяет личную жизнь, работу, спорт, здоровье, саморазвитие, финансы и планы на будущее. Оно помогает распределять время, контролировать выполнение задач, формировать полезные привычки и видеть свой прогресс.

### 1.2. Проблема
Планы, задачи, привычки, цели и финансы обычно живут в разных приложениях, заметках и в голове. Из-за этого:
- трудно увидеть свой день и баланс сфер жизни целиком;
- задачи теряются и переносятся бесконечно;
- привычки бросаются, потому что не видно серии и прогресса;
- большие цели и мечты остаются абстрактными, без конкретных шагов.

### 1.3. Решение
Одно приложение с восемью тематическими блоками, общим календарём, системой привычек, графиками прогресса, наградами и ИИ-помощником, который видит все данные и даёт персональный ежедневный обзор.

### 1.4. Целевая пользовательница
Женщина, которая совмещает работу, спорт, личную жизнь и саморазвитие, хочет эффективно управлять временем и работает в основном с ноутбука. Ценит красивый, спокойный и современный интерфейс.

## 2. Цели и метрики успеха

| Цель | Метрика |
|---|---|
| Ежедневное использование | Приложение открывается каждый день, обзор дня просматривается утром |
| Контроль задач | Доля выполненных задач за неделю растёт; число просроченных задач снижается |
| Формирование привычек | Растёт средний процент выполнения привычек за неделю и длина серий |
| Движение к целям | Растёт средний прогресс по целям (доля выполненных шагов) |
| Финансовая дисциплина | Расходы месяца укладываются в лимит бюджета |

## 3. Функциональные требования

### 3.1. Общие возможности (во всех блоках)
- **Добавлять, редактировать и удалять** задачи, события, цели, мечты, привычки, финансовые операции, тренировки, записи веса, записи благодарности и личные победы.
- **Отмечать выполненные дела** одним нажатием на чекбокс.
- **Просматривать расписание** по дням и по месяцам.
- **Отслеживать прогресс** через графики, кольца прогресса и полосы.
- **Получать ежедневный обзор**: автоматический (по правилам) и персональный от ИИ.
- **ИИ-помощник**: чат с доступом к данным пользовательницы.
- Подтверждение перед удалением (встроенный диалог: «Это действие нельзя отменить»).
- Каждая задача или событие привязана к **сфере жизни**: Мой день, Работа, Здоровье и спорт, Личная жизнь, Саморазвитие, Цели, Финансы. У каждой сферы свой цвет-метка.

### 3.2. Навигация
Боковое меню слева (на телефоне выезжает по кнопке «Меню»):
1. Мой день (счётчик невыполненных задач на сегодня)
2. Моя работа (счётчик просроченных задач)
3. Здоровье и спорт
4. Личная жизнь
5. Цели и мечты
6. Мои финансы
7. Мой календарь
8. Мои достижения
9. Мои привычки (дополнительный раздел)
10. ИИ-помощник
11. Профиль (имя для приветствия)

Внизу меню — индикатор сохранения: «Сохранено в облаке» или «Сохранено на этом устройстве».

### 3.3. Блок «Мой день» (главная страница)

**Назначение:** ежедневный обзор и управление сегодняшним днём.

| Элемент | Описание |
|---|---|
| Приветствие | Зависит от времени суток («Доброе утро», «Добрый день», «Добрый вечер», «Доброй ночи») + имя из профиля; день недели и дата |
| Кольцо прогресса дня | % выполненных задач на сегодня и привычек |
| Ежедневный обзор (авто) | Сделано X из Y задач и число событий; следующее дело по времени; просроченные задачи; привычки и лучшая серия; вода; остаток бюджета месяца |
| Обзор дня от ИИ | Кнопка генерирует персональный обзор: фраза поддержки, фокус дня, что перенести, подсказка про здоровье/привычки, шаг к цели. Обзор сохраняется на текущий день |
| Расписание на сегодня | Задачи и события, отсортированные по времени, с чекбоксами |
| Быстрое добавление | Поле «Быстро добавить задачу на сегодня» + Enter |
| Перенести с прошлых дней | Список просроченных задач |
| Вода | Стаканы, которые отмечаются нажатием (цель — 8) |
| Настроение | Шкала из 5 вариантов: тяжело / так себе / нормально / хорошо / прекрасно |
| Привычки на сегодня | Кнопки-чипы для отметки, с серией дней |
| Бюджет месяца | Остаток и полоса использования лимита |
| Ближайшая цель | Цель с ближайшим сроком и её прогресс |
| Завтра | Первые 4 дела на завтра |

### 3.4. Блок «Моя работа»

| Элемент | Описание |
|---|---|
| Показатели | Открытые задачи, важные, просроченные, сделано за 7 дней |
| Список задач | Группы: Просрочено → Предстоящие → Выполнено (последние 6) |
| График | Столбцы: рабочие задачи, выполненные за каждый из последних 7 дней |
| Рабочие цели | Цели сферы «Работа» с полосой прогресса |
| Действия | Новая задача (сфера «Работа» и сегодняшняя дата по умолчанию), редактирование, удаление, отметка |

| Элемент | Описание |

| Привычки здоровья | Серия и % выполнения за неделю |

### 3.7. Блок «Мои цели и мечты»

| Элемент | Описание |
|---|---|
| Вкладки | «Цели» и «Мечты» |
| Показатели (вкладка «Цели») | Средний прогресс, активные цели, достигнутые, число мечт |

| Расчёт прогресса | Прогресс = выполненные шаги / все шаги × 100% |
| Форма | Название, тип (цель/мечта), сфера, срок, описание, шаги (каждый с новой строки). При редактировании отметки у уже существующих шагов сохраняются |

### 3.10. Блок «Мои достижения»

| Элемент | Описание |
|---|---|
| Уровень | Каждые 500 очков = новый уровень; кольцо прогресса до следующего уровня |

### 3.11. Раздел «Мои привычки»

| Элемент | Описание |
|---|---|
| Показатели | % выполнения за неделю, отметки сегодня, лучшая серия, всего отметок |

| Серия | Количество дней подряд (если сегодня ещё не отмечено, считается до вчера) |
| График | Число выполненных привычек по дням за неделю |
| Форма | Название, сфера, иконка (вода, книга, лист, сон, сердце, спорт, солнце, звезда, огонь, повтор) |

### 3.12. ИИ-помощник

| Требование | Описание |
|---|---|
| Интерфейс | Панель выезжает справа; открывается плавающей кнопкой «ИИ-помощник» или из меню |
| Контекст | В каждом запросе передаются: расписание на 7 дней, просроченные задачи, привычки (серии, %), цели и следующий шаг, вода, сон, тренировки, настроение, финансы месяца |
| Стиль ответа | По-русски, тепло, на «ты», коротко, списками; без выдуманных задач |
| Действия (инструменты) | `add_task` — добавить задачу или событие (название, дата, время, тип, сфера, приоритет); `complete_task` — отметить задачу выполненной по названию |
| Подсказки | «Спланируй мой день», «Что можно перенести?», «Как идут мои привычки?», «Дай совет по бюджету», «Какой шаг к цели сделать на этой неделе?» |
| Потоковый ответ | Текст появляется по мере генерации |
| Ошибки | Понятные сообщения: превышен лимит запросов, доступ не разрешён, ИИ недоступен вне claude.ai |
| Согласие | При первом обращении пользовательница подтверждает доступ к ИИ |

## 4. Модель данных

Все данные хранятся одним JSON-объектом (`v: 1`).

| Сущность | Поля |
|---|---|
| `items` (задачи и события) | `id, kind (task/event), title, area, date, time, priority (high/mid/low), done, doneAt, note` |
| `habits` | `id, name, icon, area, log: { "YYYY-MM-DD": true }` |
| `goals` | `id, type (goal/dream), title, area, deadline, note, steps: [{ id, t, done }]` |
| `fin` | `id, type (income/expense), amount, cat, date, note` |
| `budget` | число, лимит расходов на месяц |
| `health.water` | `{ дата: число стаканов }`, `waterGoal` = 8 |
| `health.sleep` | `{ дата: часы }` |
| `health.weight` | `[{ id, date, kg }]` |
| `health.workouts` | `[{ id, date, type, min }]` |
| `mood` | `{ дата: 1–5 }` |
| `gratitude` | `[{ id, date, text }]` |
| `achievements` | `[{ id, title, area, date, note }]` |
| `overview` | `{ date, text }`, сохранённый ИИ-обзор дня |
| `name`, `demo` | имя для приветствия; флаг примерных данных |

### 4.1. Хранение и синхронизация
- **Основное хранилище:** личный облачный документ пользовательницы (`data/users/<id>/lifeapp`), закрытый от всех, включая владельца страницы. Доступен с любого устройства.
- **Резервное:** localStorage браузера (используется, если облако недоступно).
- Сохранение с задержкой 0,7 с после изменения, одна запись за раз, без потери последних правок.
- При первом запуске загружаются **примерные данные** (баннер «Очистить примеры» сбрасывает их и начинает с чистого листа).

## 5. Дизайн и UX

### 5.1. Стиль
- **Современный, пудрово-розовый.** Светлая румяная основа, глубокий сливово-коричневый текст, пудрово-розовый акцент.
- **Цветовые токены:** фон `#FAF1F1`, поверхность `#FFFFFF`, мягкий `#F7E4E6`, линии `#F0D9DD`, текст `#3E2A31`, вторичный текст `#8C7279`, акцент `#D88C9C`, глубокий акцент `#B65A71`.
- **Цвета сфер:** лаванда (работа), шалфей (здоровье), персик (личное), небесный (саморазвитие), золото (цели).
- **Семантические цвета:** успех `#5E9F7E`, предупреждение `#D49A3A`, критично `#C9566B`.
- **Шрифты:** Unbounded (заголовки), Manrope (текст); оба поддерживают кириллицу.

### 5.2. Компоненты
- Красивые карточки со скруглением 20 px, тонкой рамкой и мягкой розовой тенью.
- Градиентный блок приветствия на главной.
- Удобные линейные иконки (SVG) для каждого раздела и действия.
- Графики прогресса: кольца, столбчатые, линейные и кольцевые диаграммы с градиентной заливкой и выделенной последней точкой.
- Чипы-метки: сфера, дата, «Важно», «Просрочено», «Событие», «Достигнуто».
- Модальные формы добавления и редактирования; кнопки действий появляются при наведении на строку.

### 5.3. Адаптивность и доступность
- Ноутбук: боковое меню + сетка карточек (до 4 колонок).
- ≤ 860 px: меню выезжает, карточки в одну колонку.
- ≤ 460 px: упрощённый календарь.
- Видимый фокус клавиатуры, aria-подписи у иконок-кнопок, Esc закрывает окна, поддержка `prefers-reduced-motion`.

## 7. Пользовательские сценарии

1. **Утро.** Открываю «Мой день» → читаю обзор → нажимаю «Обзор дня от ИИ» → вижу, на чём сфокусироваться.
2. **В течение дня.** Отмечаю выполненные задачи, стаканы воды и привычки; быстро добавляю новую задачу.
3. **Планирование недели.** Открываю «Мой календарь» → выбираю день → добавляю события.
4. **Работа с целью.** В «Целях и мечтах» создаю цель с шагами → отмечаю шаги → прогресс растёт.
5. **Финансы.** Вношу расход → вижу остаток бюджета и разбивку по категориям.
6. **Вечер.** Отмечаю настроение, пишу запись благодарности, записываю сон.
7. **Мотивация.** В «Моих достижениях» смотрю уровень, полученные награды и записываю победу.
8. **Помощь ИИ.** «Добавь на завтра в 9:00 звонок врачу» → помощник сам создаёт событие.

## 8. Ограничения MVP

- Нет push-уведомлений и напоминаний по времени.
- Нет повторяющихся задач и событий (например, «каждый понедельник»).
- Нет недельного вида календаря (есть месяц и день).
- Нет экспорта данных в файл.
- Нет синхронизации с Google Calendar и другими сервисами.
- ИИ работает только при открытии приложения на claude.ai.
- Одна валюта (₸) и один язык (русский).

## 10. Критерии приёмки MVP

- [x] Восемь блоков: Мой день, Моя работа, Моё здоровье и спорт, Моя личная жизнь, Мои цели и мечты, Мои финансы, Мой календарь, Мои достижения
- [x] Добавление, редактирование и удаление целей, событий и остальных записей
- [x] Отметка выполненных дел
- [x] Просмотр расписания по дням и месяцам
- [x] Отслеживание прогресса на графиках
- [x] Ежедневный обзор (автоматический и от ИИ)
- [x] ИИ-помощник с доступом к данным и действиями
- [x] Формирование и контроль привычек (трекер, серии, %)
- [x] Пудрово-розовый современный стиль, карточки, иконки, графики
- [x] Сохранение данных между сеансами
